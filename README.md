# bluewaveenergy-web-gatsby-react

Bluewave Energy web portal https://www.bluewaveenergy.ca/

For development we need to create ENV file in root directory (e.g. .env.development ) which contains some variables.

PARKLAND_SPACE_ID = value;

PARKLAND_ACCESS_TOKEN = value;

PARKLAND_PREVIEW_TOKEN = value;

PARKLAND_ENV = DEV;

GATSBY_GOOGLE_MAP_APIKEY = value;

Above ENV file is for just development purpose only for other environments we are going to add in ENV variables in AWS amplify.
